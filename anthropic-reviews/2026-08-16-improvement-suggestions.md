## 1. Adopt Claude 5-generation context-engineering deletion-first advice

## 3. Fold new session-hygiene practices into README §Session Hygiene

**Source:** [Maximizing the value of your Claude Code sessions — claude.com/blog, 2026-08-14](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions), by Lydia Hallie. Five practices for reducing token cost + preserving prompt cache: (1) `/clear` between tasks; (2) set model + effort **before starting** — changing either mid-conversation busts the prompt cache; (3) `@-mention` files instead of naming them — the file attaches directly, saves a Read call (or a search if Claude has to find it); (4) add quiet flags to noisy commands, or run them in a subagent — command output stays in conversation for the rest of the session; (5) `/context` once in a fresh session to see what's loaded (CLAUDE.md, MCP tool definitions), so you can cut anything unnecessary.

### Why it's relevant

The harness's [`README.md:850–870`](../README.md) **Session Hygiene** section already covers `/clear`, `/compact`, subagents for research, and `/btw` for side questions. The May 1 [Prompt Caching is Everything](./2026-05-01-improvement-suggestions.md#1-cite-lessons-from-building-claude-code-prompt-caching-is-everything--add-one-sentence-clear-vs-compact-nuance) run already captured *"`/clear` vs `/compact` nuance"* as `APPLIED`. This post adds **three practices the table doesn't have** and **one deepening** of an existing row:

1. `/context` in a fresh session — new; nothing in the table today for "know what's loaded."
2. `@-mention` files instead of naming them — new; distinct from "use subagents for research" (that's for reading many files).
3. Quiet flags on noisy commands — new; the harness's hooks section mentions running noisy tools via hooks, but not this specific "add `--quiet`" pattern.
4. Set model + effort before starting — the post frames this as a **cache-preservation** rule, not just an ergonomic one; the May 1 §1 caching bullet in the README should get one clause added.

### Concrete change

**`README.md:862–869` — Session Hygiene table:** add three new rows immediately before the closing `/btw` row. Insert after the "Use subagents for research" row:

```diff
 | **Use subagents for research** | When Claude needs to read many files | Research in a subagent returns a summary. Direct exploration fills YOUR context with file contents. |
+| **`/context` in a fresh session** | Once at start of substantive work | Shows CLAUDE.md + MCP tool definitions + auto-loaded skills that are actually in context. Prune anything unnecessary before the session builds up further. ([source](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions)) |
+| **`@-mention` files instead of naming them** | Whenever you know the exact path | Attaches the file directly to the message — skips a Read call (or a search if Claude has to find it). Cheaper and more literal than "look at `src/foo.ts`". |
+| **Quiet flags on noisy commands (or run in a subagent)** | Any Bash call that emits >~100 lines of routine output | Command output enters conversation for the rest of the session. Prefer `--quiet` / `--silent` / `2>/dev/null` where the noise isn't the signal, or pipe through a subagent that summarizes. |
 | **`/btw` for side questions** | Quick questions mid-task | Answer appears in overlay, never enters conversation history. Zero context cost. |
```

**Optional companion touch — `README.md` §"Why Not Superpowers" caching bullet:** if the maintainer wants, extend the May-1 `APPLIED` caching sentence with *"and lock model + effort before the session starts — mid-conversation changes bust the prompt cache."* That's a one-clause add; skip if it feels like scope creep.

### Expected payoff

The Session Hygiene table stays the canonical operator-facing summary of context-preservation practices. Without this addition, three concrete, first-party-endorsed Claude Code tips live only in a blog post; with it, they live where operators look for them.
