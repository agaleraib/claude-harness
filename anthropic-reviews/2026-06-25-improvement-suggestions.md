## 6. Cite "Agentic coding and persistent returns to expertise" in the README "Why Not Superpowers" evidence list

**Source:** [Agentic coding and persistent returns to expertise — anthropic.com/research, 2026-06-16](https://www.anthropic.com/research/claude-code-expertise). Anthropic Research paper drawing on **~400,000 Claude Code sessions from ~235,000 users** (Oct 2025 – Apr 2026). Key finding: *"The greater domain expertise a person brings to a session, the more work Claude does per instruction; on coding tasks, every major occupation succeeds at nearly the same rate as software engineers."*

### Why it's relevant
The README's **"Why Not Superpowers / Heavy Skill Systems?"** section (lines ~21–35) builds an evidence list for the harness's lean-context thesis — context bloat, instruction-ignoring, AGENTbench's "process skills decrease success rates," the April 23 postmortem. The Anthropic research finding is **adjacent but not identical**: it shows that *user-side* expertise matters more than tool-side scaffolding (more domain knowledge → more agentic delegation), which corroborates the harness's "criteria-not-process" instinct — but it's an evidence point about *users*, not about *harness shape*.

This is the same shape as **2026-04-26 §1** and **2026-04-28 §1** (postmortem-as-evidence citations) and **2026-05-07 §2** (Claude Security cite into the same evidence block). Pattern: when Anthropic publishes a research finding adjacent to the harness's thesis, the lean move is one bullet in the existing evidence list.

### Why this is `defer`, not `apply`
