## 3. Cite "Agentic Coding and Persistent Returns to Expertise" (400K-sessions research) in README "Why Not Superpowers" evidence list

**Source:** [How Claude Code is used in practice / "Agentic Coding and Persistent Returns to Expertise" — anthropic.com/research, June 2026](https://www.anthropic.com/research/claude-code-expertise) (analysis of ~400,000 Claude Code sessions from ~235,000 users, October 2025 – April 2026).

### Why it's relevant

The published finding: **users own 70% of all planning decisions; Claude owns 80% of all hands-on execution work**. And: **expert-rated sessions achieve 28–33% verified success versus 15% for novice sessions**, with **expert users triggering ~12 Claude actions per prompt versus ~5 for novices** (generating 3,200 vs 600 words of output).

This is the exact division-of-labor the harness's `README.md:38–95` architecture encodes:

- **Human planning surface**: `spec-planner` (interviews the user before code is written); `.harness-profile` (audience/stakes questionnaire); `docs/plan.md` (human-curated wave board).
- **Claude execution surface**: `orchestrator` (dispatches to opus/sonnet/haiku); `generator` (sustained builder); `code-reviewer` (adversarial post-execution).
- **Human checkpoints**: after spec-planner, after code-reviewer, after ui-evaluator (per `README.md:1080–1091` "Multi-agent coordination (2026 trend)").

The 400K-sessions research is **empirical first-party validation** that this split is what actual expert users converge on. The 12-actions-per-prompt datum is also relevant: it's why the harness lets skills/agents run multi-step tools without asking for confirmation on each — expert-level use = long agent runs per instruction, not micro-managed roundtrips.

Adding the citation to "Why Not Superpowers" strengthens the evidence base with an empirical (not just theoretical or postmortem) datapoint.

### Why it's relevant
