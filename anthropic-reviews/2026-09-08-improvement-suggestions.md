## 4. Extend README's Session-Management practices table with the three `maximizing-value` tips the harness doesn't already cover

**Source:** [Maximizing the value of your Claude Code sessions — claude.com/blog, 2026-08-14](https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions). Six practices from Anthropic's own engineers for running efficient Claude Code sessions: **(1)** `/clear` between unrelated tasks; **(2)** set model + effort *before* starting (changing mid-conversation busts the prompt cache); **(3)** `@`-mention files instead of naming them (attaches the file directly, saves a Read/search call); **(4)** add quiet flags to noisy commands or run them in a subagent (command output stays in context for the rest of the session); **(5)** `/context` to audit what's actually consuming the startup payload; **(6)** `/compact` before you walk away (preserves cache prefix, unlike `/clear`).

- `/compact Focus on [X]` — covered at `README.md:865`.
- Set model + effort early — implicitly covered by `.harness-profile`'s `model.primary` + `effort_default` pin.

The remaining **three tips are absent** (`grep -n "@-mention\|@ mention\|quiet flag\|/context " /home/user/claude-harness/README.md` returns no matches):
- `@`-mention files instead of naming them
- Quiet flags / subagent isolation for noisy commands
- `/context` for startup-payload audit

Each is small, model-agnostic, and reinforces the "context is your most precious resource" One Rule the README already states. Adding them as three rows in the existing Practices table is a low-cost addition.
