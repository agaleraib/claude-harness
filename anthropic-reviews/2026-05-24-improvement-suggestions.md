## 1. Cite "How Anthropic teams use Claude Code" / adopt its usage patterns

First-party roundup of how internal Anthropic teams (Infrastructure data science, Product Design, Security Engineering, plus non-engineering teams) use Claude Code day-to-day.

### Why it surfaced
This is the highest-priority *genre* for this routine — a first-party Claude Code methodology-adjacent post — so it warrants a recorded decision rather than a one-line skip. The post's concrete, transferable practices are:

1. **CLAUDE.md-driven onboarding/navigation** — new data scientists feed Claude the whole codebase; Claude reads the repo's `CLAUDE.md` files, identifies the relevant ones, and explains dependency chains.
2. **GitHub-Actions PR-comment automation** — the Product Design team auto-runs Claude on PRs to handle formatting and test-case refactoring.
3. **Incident debugging via control-flow tracing** — Security Engineering feeds Claude stack traces + docs to trace control flow, cutting 10–15-min manual scans ~3×.
4. **Framing** — "treat Claude Code as a thought partner, not a code generator; augment human workflows."
